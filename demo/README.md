# 시연 영상

[TAMACAPE-demo.mp4](TAMACAPE-demo.mp4)

- 길이: 약 63초
- 형식: MP4, H.264 / AAC, 1920 × 1080, 30fps
- 환경: Pleos Connect 에뮬레이터, `apk/TAMACAPE-0.1.0-demo.apk`
- 흐름: 홈 → 모험 지도 → 출발 준비 퀴즈 → 정답 해설 → 친구/도감 → 동요 앨범

실제 앱 녹화에서 대기 시간을 줄이고 설명 자막을 추가했습니다. 첫 장면은 차량 화면 전체이며 이후 앱 영역을 확대했습니다. 동요 장면의 소리는 앱에 포함된 동일한 예시곡 MP3를 편집 단계에서 합친 것입니다. 새 음악 생성 API 호출이나 실차 주행 시연은 포함하지 않습니다. 앱의 가사 표시는 예상 타이밍입니다.
