## 검증
- 서버 자동 검사 16개 통과. 일일 한도와 UTC 초기화는 모의 시각으로 검증하여 100회 실제 과금을 발생시키지 않았습니다.
- 앱 단위 테스트15개 및 APK 빌드 통과. 앞선 계측8개 통과 기록은 체크리스트 참조.
- 최종 배포 실제 coach HTTP200 3.124초, story HTTP200 2.436초. 한국어 3문장과 안전 약속 확인.
- 비인증401, 잘못된 메서드405, 잘못된 스테이지400.
- 기본 Cloudflare 제한만 사용했을 때 동시7회가 모두 통과하는 문제를 발견했습니다. 전역 Durable Object 적용 후 6회200, 1회429를 확인했습니다.
- 위험한 제안과 프롬프트 변경 유도에 대해 안전 규칙을 유지했습니다. 다만 잘못된 공감 표현이 있어 이후 프롬프트를 보완했습니다. 최종 위험 발언 전용 재평가와 폭넓은 아동 품질 평가는 남아 있습니다.
- Pleos 에뮬레이터에 앱 업데이트 후 보호자 접속 설정 → 실제 동화 생성 → 화면 표시 확인. pleos-ai-live-story.png 참조.
- 로컬 시연 접속 코드가 APK 압축 내부에 없음을 UTF-8/UTF-16 검사로 확인했습니다.
- OpenAI 키는 읽거나 출력하지 않았으며 기존 Cloudflare Secret만 서버에서 참조합니다. 요청·응답·키를 로그로 출력하지 않습니다. 앱 접속 코드는 API 키와 별개이며 런타임 메모리에만 있습니다.

## 남은 작업과 운영 제한
- 공유 시연 코드는 7일 만료입니다. 재시작 시 보호자 연결 설정이 필요하며 로컬 .private/family-ai-access.json은 공유하거나 커밋하지 않습니다.
- 공개 운영에는 보호자별 인증, 동의, 사용자별 할당량이 필요합니다.
- 무료 플랜 호환 Worker/SQLite 구성입니다. OpenAI API는 별도 과금되며 실제 청구액은 조회하지 않았습니다. 호출 제한은 달러 지출 상한이 아닙니다.
- 앱 실화면에서 동화까지 확인했으며 AI 대화 화면의 실제 왕복, 아동 음성 정확도, 작은 화면 시각 검증은 별도 보완 대상입니다.
- 전체 앱 체크리스트의 UI·연출·차량 실주행 미완료 항목을 이번 배포로 완료 처리하지 않았습니다.
