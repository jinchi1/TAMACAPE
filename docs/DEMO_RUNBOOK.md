# TAMACAPE 공모전 시연 초안

**소개 문구**  
타마케이프는 Pleos Connect에서 정차 중 플레이하는 안전운전 퍼즐 게임입니다. 가상 차량의 상태를 살피고 퍼즐을 해결해 모비를 성장시킵니다. 월드 1에는 스테이지 5개와 퍼즐 10개가 있으며, 완료 보상으로 모비와 방을 꾸밀 수 있습니다.

| 화면 | 보여줄 동작 | 설명 |
|---|---|---|
| 모비의 방 | 성장 형태와 장착 아이템 확인 | 퍼즐 보상으로 얻은 XP에 따라 모비가 성장합니다. |
| 모험 지도 | 잠금·완료 표시와 획득한 별 확인 | 각 스테이지에서 서로 다른 안전운전 상황을 만납니다. |
| 멈춰버린 신호 도시 | 보행자가 건널 때 기다리기 → 오른쪽 깜빡이 켜기 → 주변 확인 후 우회전 → 끄기 | 퍼즐을 풀면서 보행자 우선과 회전 후 신호 해제를 체험합니다. |
| 꾸미기 | 코스튬이나 가구 선택 | 구매 전에 모비와 방에 적용된 모습을 확인할 수 있습니다. |

새 프로필로 시연할 때는 **모험 → 잠겨버린 차고**에서 출발 준비 카드를 순서대로 누릅니다. 다음 문제에서 차량 그림을 눌러 문을 닫고 계기판 상태를 확인한 뒤, 정답 해설과 보상 상자를 보여줍니다. **설정 → 데모 모드 → 차량 데이터**에서는 샘플 스냅샷을 조회하고 하루 한 번 20 데모 XP를 받는 흐름을 보여줄 수 있습니다.

Pleos 에뮬레이터에서 오프라인 전체 플레이, 진행 복원, 주행거리 SDK 응답, 정차 제한 화면의 계측 테스트를 확인했습니다. 실차 및 에뮬레이터의 주행 이벤트 전달 검증은 남아 있습니다. [구현 체크리스트](IMPLEMENTATION_CHECKLIST.md)

프로젝트 루트에서 `./gradlew :app:assembleDebug`로 빌드합니다. 설치용 파일은 `app/build/outputs/apk/debug/app-debug.apk`입니다. `assembleRelease`가 생성하는 릴리스 APK에는 배포 서명이 필요합니다.
