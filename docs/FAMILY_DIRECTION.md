# 가족 퀴즈와 친구 수집 전환

2026-11-12 사용자 요청으로 기존 꾸미기 요구를 대체합니다.

- 코스튬/가구 대신 모비·루루·보리를 선택하는 친구 앨범.
- 루루: 1스테이지 완료 + 100코인, 보리: 3스테이지 완료 + 200코인.
- DB 2→3 이전 시 기존 구매액 1회 환급. 기존 진행과 보상 원장 보존.
- 아이가 부모와 함께 생각하는 퀴즈, 해설 후 가족 대화 질문.
- 힌트·오답 감점 폐지. 끝까지 완료하면 별 3개. 기존 기록은 보존, 재도전으로 갱신.
- 도감은 안전 약속 카드와 배지, 설정은 놀이 환경/저장 관리, 스테이지는 캐릭터가 있는 모험 카드.
- 차량 주행 제한 시 화면·오디오 중단 원칙 유지.

## AI 제안 (아직 구현하지 않음)

1. 캐릭터 AI 퀴즈 진행자: 검수된 문제와 정답을 바탕으로 아이의 답에 짧은 추가 질문과 쉬운 해설을 제공. 새 교통 규칙 생성이나 자유 채팅보다 이 기능을 우선.
2. 말로 답하기: 읽기 어려운 아이가 말하면 인식한 문장을 화면에서 확인하고 선택. Pleos SpeechToText ON_DEVICE 지원 가능성을 현재 SDK/에뮬레이터에서 검증. 음성인식 자체와 생성형 AI 대화를 구분.
3. 가족 모험 이야기: 완료한 주제와 선택 캐릭터를 넣어 3문장 동화 생성. 검수된 안전 약속을 반드시 포함.
4. 복습 추천은 우선 규칙 기반: 어려워한 주제를 다음 퀴즈로 추천. AI라고 표시하지 않음.

권장 1차 범위: 검수된 퀴즈 + 읽어주기 + 제한된 AI 후속 질문. 서버 AI는 부모 활성화, 아동 이름/원음 저장 없이 최소 텍스트만 전달하는 설계. 오프라인은 현재 고정 질문으로 계속 진행.

공식 확인:
- https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/SpeechToText/intro
- https://pleos.ai/playground/resources/en/api-reference/connect-sdk

공식 STT 문서는 v3.3.1 기준이며 앱의 기존 Vehicle SDK 2.3.2와 자동 호환된다고 가정하지 않습니다. LLM 서비스 접근·승인·가격·사용 가능 모델은 미검증입니다.

## 최신 공식 문서 정정 (2026-11-12)

Pleos Playground 2026-10-19 릴리스에서 LLM SDK 제공 종료를 확인했습니다.
기존 SDK 개요의 LLM 언급을 현재 지원으로 해석하면 안 됩니다.
Gleo Interface는 앱 function 호출 통합이며 앱 내부 자유 텍스트 생성 API와 다릅니다.
https://document.pleos.ai/docs/pleos-only/release-note/playground-release-note

SpeechToText 3.3.1의 ON_DEVICE 모드를 앱에 연결했습니다. 사용자 요청 시에만 시작하고
20초 제한, 종료/취소, 화면 전환·주행 제한 시 자원 해제 및 늦은 콜백 무시를 적용합니다.
인식 결과는 화면에서 확인한 후 답안에 반영하며 정답 판정은 기존 검수된 콘텐츠가 담당합니다.
생성형 AI 진행자·동화는 서버리스 중계 또는 차량 내 모델 선택을 기다리는 상태로 미구현입니다.
