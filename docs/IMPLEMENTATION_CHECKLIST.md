## 최근 검증

- `testDebugUnitTest`의 도메인 테스트 3개로 전체 스테이지 순차 해금, 단계 건너뛰기 거부, 완료 재요청, 순서 퍼즐과 복수 선택을 확인했습니다.
- 퍼즐 선택 순서를 현재 진행과 함께 로컬에 저장합니다. Room 도입 시 기존 체크포인트도 이전합니다.
- `assembleDebug` 통과. 기존 Pleos 에뮬레이터 데이터에 APK를 덮어 설치한 뒤 2스테이지의 선택 상태와 기존 코인이 프로세스 강제 종료 후 복원되는지 확인했습니다.

- Room APK를 덮어 설치해 2스테이지 답안, 코인 50개, 안전모 장착을 복원했습니다. 2스테이지 완료 후 재진입 및 프로세스 재실행을 거쳐 코인 150개와 최초 완료 보상 키 2개를 확인했습니다. 단위 테스트와 APK 빌드가 통과했습니다.

- Pleos Android 계측 테스트에서 별도 DB에 동일 완료 요청을 동시에 보냈습니다. 요청 1건만 저장됐고, 초기화 후 진행·아이템·원장이 비워져 최초 보상을 다시 받을 수 있었습니다.
- Pleos 화면 테스트에서 세 설정을 변경하고 강제 종료 뒤 복원했습니다. 초기화 확인창에서 취소한 뒤 코인 150개가 유지됐습니다. 단위 테스트 3개, 계측 테스트 1개와 APK 빌드가 통과했습니다. 사운드 설정은 오디오 구현 시 연결하며 데모 차량 데이터는 4단계에서 구현합니다.
- Pleos 가로 화면에서 홈 성장 표시·장착, 지도 진행과 스테이지 소개, 코스튬·가구 프리뷰를 확인했습니다. 테스트 프로필에서 민트 러그를 구매해 75코인 차감과 재실행 후 방 배치를 검증했습니다. 단위 테스트 3개와 APK 빌드가 통과했습니다.
- Room 스키마 1→2 업데이트에서 이전 코인·가구·별을 보존했습니다. Pleos에서 힌트를 사용해 3스테이지를 완료하고, 보상 상자를 열어 별 2개와 4스테이지 해금을 확인했습니다. 재실행 뒤 별 등급과 잔액이 유지됐습니다. 단위 테스트 4개, 계측 테스트 1개 및 APK 빌드가 통과했습니다.

- 성장 곡선을 100/300/500 XP에서 Lv.10/20/30에 도달하도록 조정했습니다. Pleos에서 기존 300 XP와 코인을 보존한 채 4·5스테이지를 완료하여 Lv.30에 도달했습니다. 단위 테스트 5개와 APK 빌드가 통과했습니다.
- Pleos 해상도를 1024×600 및 1920×1080으로 강제 변경했을 때 시스템 분할 영역이 화면 밖까지 유지되어 작은 차량 화면은 시각 검증하지 못했습니다. 기본 2560×1440 및 160dpi로 복원했습니다.
- 기본 Pleos 화면에서 키보드 Tab으로 TAMACAPE 버튼에 포커스가 이동하는 것을 확인했습니다.

- 별도 Pleos 테스트 앱에서 승합차와 담벼락 그림을 직접 눌렀습니다. 프로세스 재시작 후 선택 복원, 해설 출처, 별 3개와 도감 해금을 확인했습니다. 단위 테스트 6개와 기본 앱 APK 빌드가 통과했습니다.
- Pleos에서 방향지시등 연습을 실행해 왼쪽 점등 시 우회전 차단, 오른쪽 점등 후 우회전, 신호 해제와 해설 출처까지 확인했습니다. 단위 테스트 7개와 APK 빌드가 통과했습니다.

- Pleos 기본 네트워크가 없는 상태에서 격리된 새 프로필로 월드 1의 5개 스테이지와 10개 퍼즐을 모두 완료했습니다. 1스테이지 도어 상태가 앱 재실행 후 복원됐고, 500 XP·500코인·별 15개와 도감 업적이 확인됐습니다. 테스트 앱을 삭제하고 원래 네트워크 설정을 복원했습니다.
- 최종 APK에서 도어를 닫으면 이전 열림 안내가 지워지고 새 계기판 상태가 표시되는 것을 재검증했습니다. 단위 테스트 7개와 APK 빌드가 통과했습니다.

- Pleos 디버그 APK에서 정차 시 누적거리 조회가 SDK 반환값 0.0으로 완료됐고, 데모 1234.5 km 표시 및 조회값 삭제를 확인했습니다. 잔액 375코인은 유지됐습니다. 일반 릴리스 APK 매니페스트에는 CAR_DRIVE 권한이 포함되지 않습니다. 단위 테스트 7개와 디버그·릴리스 빌드가 통과했습니다.

- Pleos 계측 테스트에서 제한 상태를 앱에 전달하여 게임 버튼이 제거되고 주차 허용 상태에서 복원되는 것을 확인했습니다. 단위 테스트 8개, 계측 테스트 2개, 디버그·릴리스 APK 빌드가 통과했습니다.
- 설치 이미지에 `hmg_car_service` 명령이 없었습니다. 공식 Virtual Console은 DDS OFFLINE 상태로, 콘솔 주행 중에도 Android 화면의 P 및 0 km/h가 유지됐습니다. 앱 시작 시 시스템 차단 및 실제 제한 콜백은 미검증입니다. 콘솔 P 상태 복원, 테스트 패키지 삭제 및 포트 포워딩 해제를 완료했습니다.
- SDK AAR에 CarInfo VIN 조회가 있지만 CAR_INFO 조회 권한과 개인정보 처리 범위가 필요합니다. 거리 반환 단위와 승인된 차량 식별 경로가 확인될 때까지 차량 동행 보너스를 지급하지 않습니다.
- 정답 확인과 보상 상자 열기에 효과음을 연결했습니다. 사운드 설정을 끄거나 제한 상태가 되거나 앱을 벗어나면 재생을 중단합니다. 단위 테스트 8개와 Pleos 계측 테스트 2개가 통과했습니다. 실제 주행 이벤트에 따른 음소거와 음량은 현장 검증 항목으로 남아 있습니다.
- 시연용 동행 보너스를 데모 스냅샷에 연결했습니다. Pleos에서 +20 데모 XP, 같은 날짜 재수령 차단, 강제 종료 후 수령 상태 복원과 게임 XP 500 유지까지 확인했습니다. 단위 테스트 8개와 디버그 APK 빌드가 통과했습니다. 실차 보너스는 별도 검증 항목입니다.

- CAR_DRIVE가 없는 격리 APK를 Pleos에 설치해 차량 조회 권한 안내와 첫 퍼즐 진입을 확인했습니다. 시연 문서는 초안 상태입니다.
- UI 콘셉트에 맞춰 어두운 화면과 아이콘 탭, 방 일러스트와 투명 모비, 월드 지도 노드, 차고 장면과 차량 조작 타일, 꾸미기 아이템 격자를 적용했습니다. Pleos 기본 해상도에서 지도 노드, 가상 도어 조작 및 코스튬 프리뷰를 확인했습니다. 단위 테스트 8개와 계측 테스트 2개가 통과했습니다. 2~5스테이지 전용 배경과 작은 화면 검증은 남아 있습니다.
- 하단 탭을 한 바에 배치하고 화면 높이에 비례해 탭과 아이콘을 키웠습니다. Pleos에서 3스테이지 선택, 보행자 대기, 가상 깜빡이 조작, 해설과 다음 퍼즐 전환을 확인했습니다. 단위 테스트 8개와 디버그 빌드가 통과했습니다.
